# FastAPI Telegram Bot Analytics API

![Интерфейс FastAPI Analytics](mockup.png)

Высокопроизводительный аналитический микросервис для сбора, хранения и агрегации метрик Telegram-ботов с авторизацией по API-ключам и хранением данных в асинхронной базе данных SQLite (`aiosqlite`).

## 🚀 Основной стек технологий
- **Backend:** FastAPI, Python 3.10+
- **Асинхронная БД:** aiosqlite
- **Валидация данных:** Pydantic v2
- **Запуск:** Uvicorn

## 🛠️ Функционал
- **Логирование событий ботов:** Сохранение пользовательских команд, переходов, кликов по кнопкам и интеракций с метаданными.
- **Агрегация статистики:** Получение общего количества событий, уникальных активных пользователей за определенный период (1-90 дней).
- **Разделение по типам событий:** Подробный breakdown событий каждого бота.
- **Временные ряды:** Построение динамики активности пользователей по дням.
- **Безопасность:** Защита всех эндпоинтов сбора и агрегации с помощью заголовка `X-API-Key`.

## 📂 Структура проекта
- `main.py` — Главная точка входа, конфигурация роутов FastAPI.
- `database.py` — Асинхронные запросы к БД SQLite с использованием индексов для ускорения поиска.
- `models.py` — Pydantic-модели валидации запросов и ответов.
- `middleware.py` — Middleware авторизации по X-API-Key заголовкам.
- `config.py` — Конфигурация приложения и переменных окружения.

## ⚙️ Установка и запуск

1. Склонируйте репозиторий.
2. Создайте файл `.env` из `.env.example`:
   ```bash
   cp .env.example .env
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите сервис:
   ```bash
   python main.py
   ```

## 📡 Эндпоинты API

| Метод | Путь | Описание |
|---|---|---|
| **POST** | `/events` | Логирование нового события бота (требуется X-API-Key) |
| **GET** | `/stats/{bot_id}` | Статистика по конкретному боту (требуется X-API-Key) |
| **GET** | `/stats` | Системная статистика по всем ботам (требуется X-API-Key) |
| **GET** | `/health` | Проверка жизнеспособности сервиса |

### Пример отправки события через `curl`:
```bash
curl -X POST "http://127.0.0.1:8000/events" \
     -H "X-API-Key: your_secure_api_key_here" \
     -H "Content-Type: application/json" \
     -d '{"bot_id": 551048892, "user_id": 12345678, "event_type": "command_start", "details": "/start command from new user"}'
```
