Телеграм-бот для автоматической продажи цифровых товаров с интеграцией API крипто-платежей (Cryptomus/CryptoPay) на базе асинхронного фреймворка `aiogram 3.x`.

## 🛠️ Основной стек технологий
- **Фреймворк:** aiogram 3.x (Asyncio)
- **База данных:** aiosqlite (SQLite)
- **HTTP Client:** aiohttp
- **FSM (Конечные автоматы):** для добавления товаров администратором

## 🚀 Основной функционал
- **Каталог товаров:** Удобный просмотр товаров пользователями с помощью динамических Inline-клавиатур.
- **Крипто-платежи:** Автоматическая генерация счетов на оплату в USDT (TRC-20) с авто-проверкой статуса транзакции через вебхуки или ручные запросы.
- **Автовыдача:** Мгновенная отправка оплаченного товара (код доступа, ссылка, файл) сразу после подтверждения транзакции.
- **Панель управления:** Полноценная FSM-админка для добавления товаров, удаления позиций из каталога и просмотра статистики.

## ⚙️ Установка и настройка

1. Склонируйте репозиторий.
2. Скопируйте `.env.example` в `.env` и укажите данные:
   ```env
   BOT_TOKEN=12345678:AaBbCc...
   CRYPTO_PAY_TOKEN=mock_crypto_pay_token
   ADMIN_IDS=12345678
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите бота:
   ```bash
   python bot.py
   ```

## 📂 Структура проекта
- `bot.py` — Точка входа, инициализация бота и регистрация обработчиков.
- `crypto_client.py` — Асинхронный клиент для взаимодействия с крипто-эквайрингом (реализован мок-класс для локального тестирования).
- `database.py` — Слой работы с БД SQLite (содержит таблицы для пользователей, товаров и инвойсов).
- `keyboards.py` — Модуль разметки инлайн-кнопок.
- `handlers/` — Обработчики команд пользователя и администратора:
  - `user.py` — Логика покупок, инвойсов и выдачи товаров.
  - `admin.py` — Добавление и удаление товаров через Finite State Machine (FSM).
